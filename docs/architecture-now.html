Why it’s built this way

  • Agent layer ≠ model layer. Identity/memory/tools live in Hermes; the token-predictor is a detail behind a URL.
  • Same Choomfie everywhere. Claude Code, Claude API, OpenAI, or a local model — flip base_url, behavior holds.
  • Subscription, not metered. Strip ANTHROPIC_API_KEY from the sidecar → SDK rides your Pro/Max OAuth.
  • ToS guardrail. Owner-only allowlist. Serving other Discord users would re-distribute a single seat = the line not to cross.
Where kaitencode plugs in → kaitencode (the renamed bento-ya kanban/pipeline board) is the work backend. Choomfie’s local-mode design already polls a task queue (bentoyaApiUrl → /tasks/next) when Discord is idle. So the clean integration isn’t “put Choomfie inside kaitencode” — it’s: Hermes runs the agent, kaitencode holds the task pipeline, and idle Choomfie pulls + executes those tasks through the same brain. Two roles, one loop.
