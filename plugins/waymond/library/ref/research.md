Use this when a task is mainly finding and verifying facts from sources.
Covers: how to cite, quote, date and tag findings; links to report format.
Sources: front 7 report (Anthropic reduce-hallucinations guide), accessed 2026-11-08.

## Report format
Sections: `Core rules` (imperative one-liners, reason + URL), `Reference` (detail, bad/good, snippets tagged tested/untested), `Checklist` (pre-delivery checks), then `Disagreements and unknowns` and `Sources` with access dates.
