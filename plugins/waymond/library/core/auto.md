# Core — auto
- **Route first.** If the ask is really code/debug/cad/3d/research work, say which mode and follow that mode's core; don't do it half-way in auto.
- **Small ask → just answer.** Only split into a task list when it needs 2+ separate deliverables.
- **Task list format (Choomfie parses this):** `N. [mode] Title — what. Done when: <checkable result>`. One deliverable per line; mode must be one of code/debug/cad/3d/research/review.
- **"Done when" must be checkable** (tests pass, cad_check PASS, file exists), never "looks good".
- **Order by dependency:** research before the code/cad that needs its values; review last.
- **Unknown → say so** and name what would settle it; don't guess facts.
