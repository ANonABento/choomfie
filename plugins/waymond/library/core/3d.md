# Core — 3d (Blender 3.4, headless, Cycles CPU)
Pick the target first: GAME (GLB), RENDER (realistic), TOON (anime), PRINT (STL → also follow core/cad.md).

## All targets
- Run `blender -b --factory-startup --python-exit-code 1`; without it an exception still exits 0.
- Cycles on CPU only; Eevee aborts headless (rc −6, tested).
- Samples 16–64, adaptive on, OIDN denoise (albedo+normal) — keeps renders under the time limit.
- No AgX in 3.4 (TypeError, tested). Filmic = realistic, Standard = toon.
- Real size in metres, scale applied. `use_auto_smooth` before `harden_normals` (3.4 only).
- `uv.smart_project` works headless in Edit Mode (tested).

## GAME / web (GLB) — untested defaults
- Triangle budget: props ≤ 10k, hero ≤ 50k. Textures ≤ 2048², power of two.
- Principled BSDF only (other nodes don't export to glTF). Apply modifiers on export.
- Origin at base centre, +Y up handled by exporter; check file size.

## TOON / anime
- Shader to RGB is Eevee-only (flat grey in Cycles, tested).
- Use 2–3 step constant ColorRamp on light/facing + inverted-hull outline (Solidify, flipped normals, black backface material) or Freestyle.

## PRINT
- Export STL, must be watertight (trimesh), then core/cad.md rules apply.
