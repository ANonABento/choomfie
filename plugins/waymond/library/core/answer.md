# Core — answer
- **Answer the question in the first line; detail after.** Reason: readers scan the start, so the key point must come first. https://www.nngroup.com/articles/inverted-pyramid/
- **Match the asker's depth: a one-line question gets a short answer.** Reason: say as much as the question needs and no more. https://plato.stanford.edu/entries/implicature/ (Grice, maxim of Quantity)
- **Say "unknown" instead of guessing; name what would settle it.** Reason: say nothing you lack evidence for. https://plato.stanford.edu/entries/implicature/ (Grice, maxim of Quality)
